# 개요  
라즈베리파이5와 카메라, 모터 제어를 결합한 하드웨어 기반의 반려동물 실시간 감시 및 안전 관리 플랫폼입니다. TFLite를 이용한 객체 인식으로 반려동물의 부재를 감지하고, 이메일 알림(SMTP)을 통해 보호자에게 즉각적인 피드백을 제공합니다. 이 웹 사이트는 이러한 복잡한 하드웨어 기능을 사용자가 직관적인 UI/UX를 통해 쉽고 편리하게 관리할 수 있도록 돕는 통합 제어 센터입니다.

# 핵심 기능  
- 사용자 인증 및 관리: 회원가입 및 로그인을 통해 개인화된 반려동물 프로필 관리.
- 실시간 스트리밍 대시보드: 라즈베리 파이 카메라 피드를 웹에서 실시간으로 확인하며 모터 제어 가능.
- 실종 방지 알림 시스템: TFLite 인식 결과, 반려동물이 10초 이상 감지되지 않으면 등록된 사용자 이메일로 자동 알림 발송.
- 라이프 로그(사진첩 & 메모장): 감지된 순간의 캡처 사진 저장 및 반려동물의 건강/특이사항 메모 기능.
- 지능형 챗봇(GPT API): 저장된 활동 데이터나 반려동물 상식을 기반으로 소통하는 AI 비서.

# 사용자 경험  
- 페르소나: 외부에서도 집에 혼자 있는 강아지/고양이의 안전이 걱정되는 보호자.
- 주요 사용자 흐름: 로그인 → 대시보드(메인 페이지) 진입 → 실시간 영상 확인 및 AI 챗봇 상담 → 특이사항 메모 또는 사진첩 정리.
- UI/UX 고려사항: "안정적인 스트리밍 레이아웃", "사라짐 알림 설정의 가시성", "모바일 최적화 대시보드".

# 기술 아키텍처  
- Hardware: Raspberry Pi 5, Camera Module, Servo Motors (모터 제어).
- AI/Infra: TFLite (객체 인식), SMTP Server (이메일 전송), GPT API (챗봇).
- Frontend/Backend: Next.js (또는 React), Node.js, Socket.io (실시간 제어 및 스트리밍).
- Database: Supabase 또는 MongoDB (회원 정보, 사진첩, 메모, 탐지 로그 저장).

# 개발 로드맵  
- MVP (1단계): 회원가입/로그인 기능 및 라즈베리 파이 영상 스트리밍 연동.
- 2단계: TFLite 인식 결과에 따른 SMTP 이메일 발송 로직 및 하드웨어 모터 제어 버튼 구현.
- 3단계: 사진첩, 메모장 기능 활성화 및 GPT API 기반 챗봇 연동.

# 논리적 의존성 체인
- Auth & Database: 회원별 반려동물 데이터 매칭을 위한 DB 설계 우선.
- Streaming & Hardware Bridge: 웹 서버와 라즈베리 파이 간의 통신(Socket) 안정화.
- UI/UX Refinement: 기능들이 유기적으로 배치된 대시보드 레이아웃 완성.
- AI Intelligence: 서비스 안정화 후 GPT 챗봇을 통한 사용자 경험 고도화.

# 리스크 및 대응방안  
- 네트워크 지연: 스트리밍 지연 발생 시 해상도 동적 조절 알고리즘 적용.
- 오탐지(False Positive): 10초라는 기준 시간을 사용자가 커스텀 설정할 수 있도록 UI 제공.
