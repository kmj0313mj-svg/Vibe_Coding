# 반려동물 모니터링 웹 서비스 PRD

## 1. 프로젝트 개요
이 프로젝트는 집에 혼자 있는 반려동물을 웹에서 확인하고, 간단한 기록과 상담 기능까지 제공하는 반려동물 모니터링 서비스입니다.

현재 프로젝트는 정적 웹페이지 기반으로 구성되어 있으며, 로그인, 대시보드, 기록장(갤러리/일기), 설정, AI 챗봇 같은 화면이 이미 존재합니다.  
이 PRD의 목적은 "초보자도 어떤 기능을 왜 만드는지 이해하고, 어떤 순서로 완성해야 하는지 알 수 있게" 프로젝트 방향을 정리하는 것입니다.

## 2. 문제 정의
반려동물을 키우는 사람은 외출 중에도 다음과 같은 걱정을 자주 합니다.

- 지금 반려동물이 안전한가?
- 밥은 잘 먹었는가, 이상 행동은 없는가?
- 집 안에서 무슨 일이 일어나고 있는가?
- 중요한 장면을 나중에 다시 볼 수 있는가?

이 서비스는 위 문제를 줄이기 위해, 실시간 확인과 기록 저장, 간단한 설정, AI 상담 기능을 한곳에 모은 웹 서비스를 목표로 합니다.

## 3. 목표
이 프로젝트의 1차 목표는 아래 4가지를 안정적으로 제공하는 것입니다.

- 사용자가 로그인 후 자신의 반려동물 관리 화면에 들어갈 수 있다.
- 대시보드에서 반려동물 상태를 확인하고, 캡처/녹화/음성 송출 같은 핵심 동작을 사용할 수 있다.
- 기록장에 사진과 일기를 저장하고 다시 볼 수 있다.
- 설정 페이지에서 반려동물 이름, 알림 설정, API 키 등의 개인 설정을 저장할 수 있다.

추가 목표는 아래와 같습니다.

- AI 챗봇을 통해 반려동물 관련 질문에 답변받을 수 있다.
- 추후 라즈베리파이, 카메라, 모터, 이메일 알림 같은 실제 하드웨어 기능과 연결할 수 있는 기반을 만든다.

## 4. 주요 사용자
주 사용자는 다음과 같습니다.

- 집을 자주 비우는 반려동물 보호자
- 반려동물의 상태를 간단히 확인하고 싶은 사용자
- 복잡한 기술보다 "보기 쉬운 화면"과 "간단한 사용법"을 선호하는 사용자

## 5. 사용자 시나리오
대표적인 사용 흐름은 아래와 같습니다.

1. 사용자는 회원가입 또는 로그인한다.
2. 대시보드에 들어가 반려동물 상태를 확인한다.
3. 필요하면 화면을 캡처하거나 녹화하고, 음성 메시지를 재생한다.
4. 저장된 사진과 일기를 기록장에서 확인한다.
5. 설정 페이지에서 반려동물 이름, 알림 메일, 알림 지연 시간 등을 수정한다.
6. 궁금한 점이 있으면 AI 챗봇에 질문한다.

## 6. 핵심 기능 범위

### 6-1. 인증 기능
- 회원가입 가능
- 로그인/로그아웃 가능
- 로그인하지 않은 사용자는 보호된 페이지 접근 제한
- 현재는 `localStorage` 기반으로 동작

### 6-2. 대시보드
- 반려동물 상태 표시
- 실시간 영상 또는 영상 영역 표시
- 음성 송출 입력 기능
- 화면 캡처 기능
- 녹화 기능
- 최근 사진/최근 일기 미리보기 제공

### 6-3. 기록장
- 저장된 사진 목록 보기
- 사진 메모 수정
- 사진 다운로드 및 삭제
- 일기 작성, 조회, 삭제

### 6-4. 설정
- 반려동물 이름 저장
- 메일 알림 사용 여부 저장
- 수신 메일 주소 저장
- 알림 지연 시간 저장
- 모터 속도 저장
- OpenAI API 키 저장
- 테마 변경
- 비밀번호 변경

### 6-5. AI 챗봇
- 사용자가 질문 입력
- OpenAI API 또는 Cloudflare Worker를 통해 응답 생성
- 한국어로 반려동물 상담 스타일 답변 제공

## 7. MVP 범위
비전공자/초보자 기준으로, 처음부터 모든 기능을 완벽하게 만들기보다 아래를 MVP로 봅니다.

- 로그인/회원가입이 문제없이 동작한다.
- 대시보드 주요 버튼이 정상 동작한다.
- 캡처한 이미지와 일기가 저장되고 다시 보인다.
- 설정값이 저장 후 다시 접속해도 유지된다.
- 챗봇이 최소 1회 이상 정상 응답한다.

즉, "하드웨어 완전 연동"보다 "웹 서비스 흐름이 자연스럽게 이어지는가"를 먼저 완성합니다.

## 8. MVP 이후 확장 기능
- 실제 라즈베리파이 카메라 스트리밍 연동
- 반려동물 미감지 시 이메일 자동 발송
- 모터 제어 버튼과 실제 하드웨어 연결
- 반려동물 활동 로그 분석
- 챗봇이 저장된 기록 데이터를 참고해서 답변하도록 개선
- 관리자/일반 사용자 구분

## 9. 비기능 요구사항
- 초보자도 이해할 수 있는 단순한 화면 구조
- 모바일에서도 크게 깨지지 않는 레이아웃
- 버튼 클릭 결과가 바로 보이는 피드백 제공
- 중요한 설정은 새로고침 후에도 유지
- 오류가 나면 사용자가 이해할 수 있는 메시지 표시

## 10. 기술 방향
현재 프로젝트 기준 기술 방향은 아래와 같습니다.

- 프론트엔드: HTML, CSS, JavaScript
- 데이터 저장(현재): `localStorage`
- AI 연동: OpenAI API 또는 Cloudflare Worker
- 향후 확장:
  - 백엔드 서버 추가
  - 데이터베이스 연동
  - 라즈베리파이/카메라/모터 연동
  - 이메일 발송 기능 추가

## 11. 개발 우선순위
초보자 기준 추천 순서는 아래와 같습니다.

1. 로그인/회원가입 흐름 안정화
2. 대시보드 버튼과 화면 동작 점검
3. 사진/일기 저장 흐름 완성
4. 설정 저장 기능 안정화
5. 챗봇 연결 확인
6. 실제 하드웨어/알림 기능 확장

## 12. 리스크와 대응

### 리스크 1. 현재 저장 방식이 브라우저 전용임
- 문제: `localStorage`는 브라우저를 바꾸면 데이터가 공유되지 않음
- 대응: MVP에서는 유지하고, 이후 서버/DB 연동으로 확장

### 리스크 2. API 키 노출 가능성
- 문제: 클라이언트에서 직접 API 키를 다루면 보안상 위험할 수 있음
- 대응: 가능하면 Cloudflare Worker 또는 서버 프록시 방식 사용

### 리스크 3. 하드웨어 연동 난이도
- 문제: 웹 기능과 라즈베리파이 연동은 난이도가 높음
- 대응: 먼저 웹 UI와 저장 흐름을 완성한 뒤, 하드웨어는 2단계로 분리

### 리스크 4. 초보자에게 범위가 너무 클 수 있음
- 문제: 기능이 많아 한 번에 진행하면 막히기 쉬움
- 대응: 한 화면씩, 한 기능씩 작게 나눠서 구현

## 13. 성공 기준
프로젝트가 1차적으로 성공했다고 볼 수 있는 기준은 아래와 같습니다.

- 사용자가 로그인 후 대시보드에 진입할 수 있다.
- 대시보드에서 캡처/녹화/음성 송출 흐름을 이해하고 사용할 수 있다.
- 기록장에서 저장한 사진과 일기를 다시 확인할 수 있다.
- 설정값이 정상 저장되고 다시 불러와진다.
- 챗봇이 기본 응답을 정상 제공한다.

## 14. 초보자용 작업 원칙
이 프로젝트는 바이브코딩 초보자도 진행할 수 있어야 하므로 아래 원칙을 지킵니다.

- 한 번에 많은 기능을 만들지 않는다.
- 화면이 먼저 보이게 만들고, 그 다음 기능을 붙인다.
- 어려운 하드웨어 연동은 뒤로 미룬다.
- "지금 동작하는 최소 기능"을 먼저 만든다.
- 에러가 나면 원인을 찾기 쉽게 작은 단위로 수정한다.

## 15. 한 줄 요약
이 프로젝트는 "반려동물 보호자가 웹에서 반려동물 상태를 확인하고, 기록하고, 간단한 AI 도움까지 받을 수 있는 초보자 친화형 모니터링 서비스"를 만드는 것이 목표입니다.
